Privacy & Liability

Last updated: May 2026

Privacy

Cyph3rfall runs entirely on your Mac. It collects no analytics, no telemetry, and no usage statistics of any kind. Nothing you do inside the app is ever reported back anywhere.

All settings — idle timeout, colour preferences, glyph size, message text, shortcut keys, and everything else — are stored locally in macOS user defaults on your own machine. They never leave your Mac.

If you enable the password lock feature, authentication is handled entirely by macOS through the LocalAuthentication framework (Touch ID, Face ID, or Apple Watch). Cyph3rfall never sees or stores your credentials.

Short version: Cyph3rfall never sends anything to any server. There are no accounts, no sign-ins, no cloud sync, and no third-party SDKs embedded in the app.

This Website

cyph3rfall.app is hosted on GitHub Pages. When you visit, GitHub may log standard server information — IP address, browser type, referring URL — for operational and security purposes, in accordance with GitHub's privacy policy. These logs are outside my control and I do not receive them.

This site sets no cookies, runs no tracking scripts, and uses no third-party analytics. The Matrix rain animation on the home page is pure JavaScript with no external dependencies.

Reliability

Cyph3rfall is actively developed and runs stably on the hardware I test it on, but it is a one-person project built in collaboration with AI tooling — not a commercial software house. It can still surprise you.

If the app behaves unexpectedly — including (but not limited to) activation at the wrong time, failure to dismiss, or issues with the password lock feature — please report it on the GitHub Issues page or email dev@cyph3rfall.app. I take bug reports seriously and address them as quickly as I can.
